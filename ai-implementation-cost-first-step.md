# AI implementation cost: what the first step involves

![Cover](https://dxggowrfyirnanabowhr.supabase.co/storage/v1/object/public/site-images/site-ai-implementation-cost-first-step-1793941888.jpg)

An AI budget answers two different questions: what will it cost to get a solution working, and what will it cost to keep using it? In my view, tools and a server can start at $30. The price of building a custom system is a separate question

## Start with the work, not the model list

Write down the job you want done, the people who need access, and the applications or data involved. A tool that helps one employee draft emails is a different purchase from a system that has to run tasks on its own

A ready-made application runs on its provider's infrastructure, so you do not automatically need your own server. For a separate system that must keep operating when your computer is off, a virtual private server can provide a place to run it

I recommend a VPS for my setup. A system hosted on a personal computer stops when that machine is shut down, loses power, or loses its internet connection. An offsite server is not dependent on those conditions at home

## My running costs

I pay $200 per month for Claude Code, $20 for ChatGPT, $20 for GLM and $30 for a server. Those items total approximately $270. With smaller services such as ElevenLabs and HeyGen, my overall spending is around $300 a month

That combination fits my needs; it is not a required shopping list. I do not think free open-source models deliver the level of work small and medium-sized businesses need, though model choice should be considered against the actual task

## Subscription or API

A subscription to an AI application and programmatic model access can have separate billing. [OpenAI's billing guide](https://help.openai.com/en/articles/9039756-billing-settings-in-chatgpt-vs-platform) makes that distinction for ChatGPT and its API. API charges depend on the model, usage and features. Some eligible plans offer credits, so look at the terms of the plan you are considering

![Budget calculations](https://images.pexels.com/photos/5833259/pexels-photo-5833259.jpeg?auto=compress&cs=tinysrgb&h=650&w=940)

For an estimate, keep setup, integration and testing apart from recurring model, hosting, other service and support costs. Comparing alternatives only makes sense when they cover the same job and anticipated workload

An [AI consultation](https://matintellect.com/en/services/ai-consulting) is one way to examine those choices for a particular business. The scope determines which pieces you need and what the first step costs
